# Schema do MIRA Slide Score

## Sumário

1. Cabeçalho do deck
2. Cartão de slide
3. Ledger de montagem

## 1. Cabeçalho do deck

```text
Premissa:
Princípio organizador:
Frase de montagem:
Público:
Duração:
Quantidade de slides:
Proporção:
Dependência da narração:
Imagem inesquecível:
Sabedoria final:
```

## 2. Cartão de slide

| Campo | Conteúdo esperado |
|---|---|
| ID e título | Identificação de produção; título não precisa aparecer |
| Função dramática | Um único trabalho narrativo |
| Estado de entrada | O que o público sabe, pergunta, sente e prevê |
| Primeiro quadro | Composição legível antes do movimento |
| Ação dominante | Verbo visual que materializa o mecanismo |
| Resistência | Força que impede resultado fácil |
| Microvirada | Mudança irreversível dentro da cena |
| Informação entregue | Fatos necessários agora |
| Pista | Elemento que ganhará significado depois |
| Informação retida | Resposta ou motivo ainda adiado |
| Emoção causada | Acontecimento → avaliação → emoção |
| Metáfora ou símbolo | Relação preservada e significado atual |
| Narração | Fala curta que complementa a imagem |
| Texto de tela | Somente o indispensável |
| Estado de saída | Nova configuração visual e mental |
| Transição | Relação causal com o primeiro quadro seguinte |
| Fidelidade | Limite ou falsa inferência a bloquear |
| Handoff de movimento | Ação, câmera ou timing a resolver depois |

## 3. Ledger de montagem

| Slide | Pergunta aberta | Fato entregue | Pista | Hipótese provável | Payoff futuro | Estado emocional |
|---|---|---|---|---|---|---|

Usar o ledger para detectar revelações antecipadas, perguntas abandonadas e excesso de carga mental.
