# Gramáticas de sequência

## Sumário

1. Arco de descoberta
2. Arco de decisão
3. Arco mecanístico
4. Arco de ironia
5. Seleção

## 1. Arco de descoberta

```text
anomalia → hipótese → teste → contradição → nova hipótese → revelação → aplicação
```

Usar para ciência, investigação, estratégia e conceitos contraintuitivos.

## 2. Arco de decisão

```text
desejo → opções → primeira escolha → custo oculto → pressão → escolha moral → consequência
```

Usar quando a sabedoria depende de julgamento, responsabilidade ou valores concorrentes.

## 3. Arco mecanístico

```text
estado inicial → operação → resistência → falha → ajuste → funcionamento → limite
```

Usar para explicar sistemas técnicos sem transformar o deck em tutorial estático.

## 4. Arco de ironia

```text
expectativa → cerimônia ou promessa → resultado contraditório → comemoração inadequada → custo → revelação
```

Usar quando a contradição é parte do conceito. Não ridicularizar pessoas ou culturas quando o alvo real for sistema, incentivo ou regra.

## 5. Seleção

Escolher uma gramática dominante. Emprestar beats de outra somente quando a cadeia causal exigir. Não alternar gramáticas para variar aparência.

Toda gramática precisa terminar com transformação observável e sabedoria, não apenas resposta intelectual.
