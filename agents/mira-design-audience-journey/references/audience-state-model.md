# Modelo de estado do público

## Sumário

1. Vetores de estado
2. Mudanças válidas
3. Matriz de beat
4. Diagnósticos

## 1. Vetores de estado

| Vetor | Pergunta operacional |
|---|---|
| Perceber | Para onde está dirigida a atenção? |
| Saber | Que fatos estão disponíveis? |
| Acreditar | Que modelo explica esses fatos? |
| Perguntar | Que lacuna parece mais urgente? |
| Prever | O que parece prestes a acontecer? |
| Sentir | Que emoção surge de qual avaliação? |
| Querer | Que resultado o público deseja? |
| Temer | Que perda parece possível? |
| Julgar | Que ação ou valor parece correto? |
| Lembrar | Que imagem ou relação deve permanecer? |

## 2. Mudanças válidas

Um beat deve alterar pelo menos dois vetores. Mudanças fortes incluem:

- fato novo que invalida uma crença;
- consequência que transforma curiosidade em medo;
- escolha que transforma identificação em julgamento;
- pista que muda uma previsão;
- revelação que reorganiza lembranças;
- ação que converte conhecimento em responsabilidade.

Evitar beats que apenas acrescentem informação sem mudar interpretação, desejo ou emoção.

## 3. Matriz de beat

| Campo | Conteúdo |
|---|---|
| Estado de entrada | saber, acreditar, perguntar, sentir, querer, prever |
| Estímulo | acontecimento visível ou informação entregue |
| Operação mental | notar, comparar, prever, escolher, reconstruir |
| Avaliação | significado atribuído pelo público |
| Mudança | vetores alterados |
| Estado de saída | nova configuração |
| Necessidade seguinte | pergunta ou risco que exige continuação |

## 4. Diagnósticos

- **Exposição:** saber muda; todo o resto permanece igual.
- **Confusão:** informação muda sem inferência possível.
- **Melodrama:** sentir muda sem avaliação ou vínculo suficiente.
- **Passividade:** o público recebe respostas sem formular hipóteses.
- **Falsa imersão:** há detalhes sensoriais, mas nenhuma decisão simulada.
- **Sabedoria fraca:** acreditar muda, mas julgar e agir não mudam.
