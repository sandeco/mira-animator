# Emoção, incorporação e sabedoria

## Sumário

1. Emoção causada
2. Incorporação
3. Contraste e ritmo
4. Sabedoria transferível

## 1. Emoção causada

Usar a cadeia:

```text
vínculo ou valor → expectativa → acontecimento → avaliação → emoção → impulso
```

Exemplos de avaliação:

- ameaça a algo valorizado → medo;
- perda irreversível → tristeza;
- violação injusta → indignação;
- capacidade maior que o imaginado → assombro;
- possibilidade recuperada → esperança;
- responsabilidade por dano evitável → culpa;
- valores igualmente defensáveis em choque → ambivalência.

## 2. Incorporação

O público sente que vive a história quando:

- conhece o objetivo antes da ação;
- entende o que pode ser perdido;
- possui informação suficiente para prever;
- percebe a incerteza relevante;
- simula uma escolha;
- recebe a consequência antes da explicação;
- revisa a própria hipótese.

Detalhes sensoriais só ajudam quando tornam risco, escala, tempo ou causalidade mais perceptíveis.

## 3. Contraste e ritmo

Usar ondas, não intensidade constante:

- tensão → microalívio → complicação;
- assombro → orientação → ameaça;
- humor → silêncio → custo;
- esperança → revés → escolha;
- velocidade → pausa → revelação.

Reservar silêncio, quadro estável ou desaceleração para permitir avaliação e memória. Não confundir pausa com slide morto.

## 4. Sabedoria transferível

Testar quatro níveis:

| Nível | Resultado |
|---|---|
| Dado | O público repete um fato |
| Conhecimento | Explica uma relação |
| Julgamento | Escolhe um critério adequado |
| Sabedoria | Reconhece quando aplicar, limitar ou abandonar o critério |

Uma história MIRA deve buscar pelo menos julgamento e, quando a duração permitir, sabedoria.

Fechar com aplicação nova, não com repetição da conclusão. Mostrar o princípio funcionando em outro contexto ou formular a pergunta portátil que o público levará consigo.
