# Contrato da folha

- Escreva apenas os dois caminhos informados pelo motor.
- Envelope: `<!-- @MIRA:FAST slide=NN stage=SLUG kind=static|animated -->`, uma `section`, `<!-- @MIRA:FAST css -->` + um `style`, `<!-- @MIRA:FAST js -->` + um `script`.
- Texto visível em pt-br correto. Cor somente por CSS variables do `mira-dark`; nenhum hexadecimal no JavaScript.
- IDs e classes exclusivos usam `slug_stage`/`js_id`. Não crie triggers globais: o montador os instala.
- A capa usa título balanceável. Não escreva módulos de edição/pintura: o montador os instala.
