O defeito

Falas de demonstração do template vazam para todo deck gerado e viram o teleprompter em file://

Causa raiz confirmed

O array de fallback do teleprompter vive dentro do runtime que a Fase 1 herda inteiro (window.__miraScript no 9:16, var SCRIPT no 16x9). A Fase 3 nunca o tocava, então todo deck nascia com as falas do deck de demonstração do Mira.

Estratégia escolhida

A montagem passa a reescrever o array com as falas do plano. Escolhida sobre "esvaziar o array no template" porque assim o deck de demonstração continua funcionando sozinho e o deck gerado ganha as falas certas, inclusive do quinto slide em diante.
